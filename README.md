# ❌⭕ AVR Tic-Tac-Toe Game (CodeVision + Proteus)

> 🕒 **Note:** This project was originally developed in **June 2024** and uploaded to GitHub in **October 2025** for portfolio and documentation purposes.

This embedded system project implements a fully functional **Tic-Tac-Toe game** on an **AVR microcontroller**, programmed in **C** using **CodeVisionAVR** and simulated in **Proteus**. The game allows two players to compete using a **numeric keypad**, with visual feedback provided via **LEDs** and a **16x2 LCD**.

The system includes:

- 🎮 **Two-Player Gameplay** – Players select positions using a 4x4 numeric keypad  
- 📟 **LCD Display** – Shows current board state, turn info, and win/draw messages  
- 💡 **LED Indicators** – Highlight active player or winning status  
- 🔁 **Game Reset Logic** – Automatic board clearing after each round  
- 🔌 **Peripheral Integration** – Keypad, LCD, LEDs, and AVR I/O ports  
- 🧪 **Proteus Simulation** – Fully tested with virtual hardware components  

---

## ⚙️ Requirements

To build and simulate this project, you’ll need:

- 💻 CodeVisionAVR IDE  
- 🧪 Proteus Design Suite (v8.0 or newer recommended)  
- 🔩 AVR microcontroller (e.g., ATmega16 or ATmega32)  
- 📟 16x2 LCD module  
- 🔢 4x4 Matrix Keypad  
- 💡 LEDs for visual indicators  
- 🧩 Basic knowledge of embedded C and AVR registers
